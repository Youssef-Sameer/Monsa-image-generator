# Monsa Studio

AI product photos for MONSA (@monsa.eg). The site runs entirely in the browser and is hosted on GitHub Pages.

## Open it
- **Online:** https://youssef-sameer.github.io/Monsa-image-generator/
- **On this computer:** double-click `index.html`.

## Important: where your work is saved
Products, models, images and settings are saved **in the browser you use**, on that device only. Nothing goes to GitHub.
- Use **Admin > Settings & backup > Export backup** regularly.
- To move your work to your phone (or another computer), export a backup there and use **Import backup** on the other device.
- Clearing the browser's site data deletes your work, so keep backups.

## AI key (free)
1. Sign up at https://enter.pollinations.ai
2. Create a key.
3. Paste it in **Admin > Settings & backup**. Do this once on each device.

The key stays in that browser and is never put on GitHub.
Without a key, use **Copy prompt**. It gives you the prompt and reference photos to use in Gemini or ChatGPT, and you then upload the result back to the gallery.
